## ✨ Funcionalidades

- Mostrar propiedades en venta.
- Mostrar propiedades en alquiler.
- Renderizar propiedades dinámicamente.
- Mostrar únicamente tres propiedades en la página principal.
- Mostrar todas las propiedades en las páginas de categorías.
- Utilizar arreglos de objetos.
- Uso de condicionales para:
  - Permitir o no fumar.
  - Permitir o no mascotas.
